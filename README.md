# Мой лаунчер для Android TV

Минималистичный главный экран без рекламы и рекомендаций:
часы, дата, погода (Open-Meteo), быстрые кнопки Wi-Fi / Bluetooth / Настройки
и строка избранных приложений.

## Управление
- **ОК** на плитке — открыть приложение.
- **Долгое ОК** на плитке — сдвинуть влево/вправо, убрать, «О приложении».
- Плитка **«Приложения»** — отметить, что показывать на главном экране.
- **ОК на погоде** — сменить город.

## Сборка
GitHub Actions собирает APK при каждом push и выкладывает его в релиз `latest`.

## Установка
```
adb install -r tv-launcher.apk
adb shell cmd package set-home-activity ru.my.tvlauncher/.MainActivity
```
